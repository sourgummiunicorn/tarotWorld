# The Quiet Arcana

A calm, responsive three-card tarot experience made with plain HTML, CSS, and JavaScript. No build step, API key, or external service is required; the app can be hosted directly with GitHub Pages.

## Run locally

Open `index.html` in a browser, or serve this directory with any static file server. The Google Fonts link is optional: the page falls back to system serif and sans-serif fonts if offline.

## Reading flow

1. Choose a topic: general guidance, love, career, or personal growth.
2. Shuffle the 22-card Major Arcana deck.
3. Choose three face-down cards. Each can only be chosen once in that reading.
4. Tap each card to flip it and explore its upright or reversed meaning in the Past, Present, or Future position.
5. Once all three are revealed, read a topic-aware reflection that weaves the cards together. Restart any time for a fresh shuffle.

The language is intentionally reflective rather than predictive. All card data and fortune generation run in the browser.
